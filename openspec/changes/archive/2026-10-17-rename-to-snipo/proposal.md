# Proposal

## Why

The npm name `snipkit` is already taken, so the project cannot publish under it. Renaming the project, package, CLI, configuration convention, and public API identifiers to `snipo` gives the tool a single coherent name and unblocks publishing.

## What Changes

- Rename the npm package from `snipkit` to `snipo` and the CLI binary from `snipkit` to `snipo`.
- **BREAKING**: Rename the configuration file convention from `snipkit.config.*` to `snipo.config.*`.
- **BREAKING**: Rename public API identifiers: `SnipkitConfig` -> `SnipoConfig`, `SnipkitActions` -> `SnipoActions`, `loadSnipkitConfig` -> `loadSnipoConfig`, and the generator brand `Symbol.for('snipkit.generator')` -> `Symbol.for('snipo.generator')`.
- Update module specifiers in docs and augmentation examples from `snipkit` / `snipkit/runtime` / `snipkit/cli` to `snipo` / `snipo/runtime` / `snipo/cli`.
- Update `README.md`, `docs/*.md`, source, tests, type-tests, and the live OpenSpec specs to the new name.
- Update `repository.url` in `package.json`.
- Regenerate `dist/` from the renamed source. Leave archived OpenSpec changes and historical `CHANGELOG.md` links untouched.

## Capabilities

### New Capabilities

- (none)

### Modified Capabilities

- `generator-cli`: configuration discovery reads `snipo.config.*`, and the CLI identifies itself as `snipo` in interactive selection and in errors and guidance.
- `programmatic-api`: the package, its entry points, and its public identifiers use the `snipo` / `Snipo` name, and the no-configuration path no longer references `snipkit.config.*`.

## Impact

- Package identity: `package.json` (`name`, `bin`, `repository.url`); npm publish surface.
- Source: `src/config/load-config.ts` (`CONFIG_BASENAME`, `loadSnipkitConfig`, `SnipkitConfig`), `src/config/define-config.ts`, `src/config/define-generator.ts` (brand symbol), `src/index.ts`, `src/runtime.ts`, `src/runtime/hooks.ts`, `src/runtime/resolve-generator.ts` (messages), `src/cli/run.ts`, `src/actions/types.ts`, `src/actions/index.ts`.
- Types and tests: `type-tests/action-extension.ts`, 10 files under `test/`, plus fixture names and temp-directory prefixes.
- Docs: `README.md` and 6 files under `docs/`.
- Specs: `openspec/specs/generator-cli` and `openspec/specs/programmatic-api` after this change is archived.
- Out of scope: the local working-directory name, the GitHub repository rename, `CHANGELOG.md` history, archived OpenSpec changes, `.idea/`, and committed `dist/` contents (regenerated by the build).
