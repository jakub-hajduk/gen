# Proposal

## Why

The npm name `snipo` is too close to an existing name, so the project still cannot publish cleanly under it. Renaming to the scoped package `@trut/gen` with the bare tool name `gen` gives the package a publishable identity that is distinct from the clash.

## What Changes

- Rename the npm package from `snipo` to `@trut/gen` and the CLI binary from `snipo` to `gen`.
- **BREAKING**: Rename the configuration file convention from `snipo.config.*` to `gen.config.*`.
- **BREAKING**: Rename public API identifiers: `SnipoConfig` -> `GenConfig`, `SnipoActions` -> `GenActions`, `loadSnipoConfig` -> `loadGenConfig`.
- Namespace the generator brand from `Symbol.for('snipo.generator')` to `Symbol.for('@trut/gen.generator')` so it cannot collide in Node's global symbol registry.
- Update module specifiers, the module-augmentation example, and the CLI usage text: `@trut/gen`, `@trut/gen/runtime`, `@trut/gen/cli`, and the bare `gen` command, help, and c12 name.
- Update the self-version check in the CLI to match the scoped package name.
- Update `repository.url` in `package.json` to `https://github.com/jakub-hajduk/gen`.
- Update `README.md`, `docs/*.md`, source, tests, type-tests, and the live OpenSpec specs. Regenerate `dist/`. Leave archived changes and `CHANGELOG.md` history untouched.

## Capabilities

### New Capabilities

- (none)

### Modified Capabilities

- `generator-cli`: configuration discovery reads `gen.config.*`, and the CLI identifies itself as `gen` in interactive selection and in errors and guidance.
- `programmatic-api`: the package, its entry points, and its public identifiers use the `@trut/gen` / `Gen` name, and the no-configuration path no longer references `snipo.config.*`.

## Impact

- Package identity: `package.json` (`name`, `bin`, `repository.url`); npm publish surface.
- Source: `src/config/load-config.ts` (`CONFIG_BASENAME`, c12 `name`, `loadSnipoConfig`, `SnipoConfig`), `src/config/define-config.ts`, `src/config/define-generator.ts` (brand symbol), `src/index.ts`, `src/runtime.ts`, `src/runtime/hooks.ts`, `src/runtime/resolve-generator.ts` (messages), `src/cli/run.ts` (help text, version check, import), `src/actions/types.ts`, `src/actions/index.ts`.
- Types and tests: `type-tests/action-extension.ts`, 10 files under `test/`, plus fixture names and temp-directory prefixes.
- Docs: `README.md` and 6 files under `docs/`.
- Specs: `openspec/specs/generator-cli` and `openspec/specs/programmatic-api` after this change is archived.
- Out of scope: the local working-directory name, the GitHub repository rename, `CHANGELOG.md` history, archived OpenSpec changes, `.idea/`, and committed `dist/` contents (regenerated by the build).
